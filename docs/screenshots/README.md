# Screenshots Directory

This directory contains example screenshots showcasing Co-Pilot SE capabilities.

## Required Images

Please save the following screenshots in this directory:

1. **architecture-wizard.png** - The Architecture Wizard interface showing the input form with example scenarios
2. **requirements-gathering.png** - Requirements Gathering Progress showing the 7 domains with progress bars
3. **logical-diagram.png** - Logical Architecture Diagram showing Azure services and data flow
4. **cost-estimate.png** - Cost Estimate breakdown showing pricing by Azure service
5. **hld-document.png** - High-Level Design Document showing the generated HLD format

## Image Specifications

- Format: PNG (preferred) or JPG
- Resolution: At least 1200px wide for clarity
- File naming: Use kebab-case as shown above
- Optimization: Compress images to keep repository size reasonable (use tools like TinyPNG)

## Adding Screenshots

To add or update screenshots:

1. Export/capture the screenshot
2. Optimize the image size
3. Save to this directory with the appropriate name
4. Update `README.md` references if needed
5. Commit and push changes
