# MCP Server for Co-Pilot SE

Model Context Protocol server implementation for GitHub Copilot Chat integration.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```

## Environment Variables

Copy `.env.example` from root and configure MCP-specific settings.

## Integration with GitHub Copilot Chat

See [MCP Integration Specification](../docs/05-mcp-integration-spec.md) for detailed setup instructions.
